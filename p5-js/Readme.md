# Inicio de Repo para codigo creativo

En este repositorio se almacenará código creativo que puede ser utilizado para proyectos de arte, diseño, música y otras formas de expresión creativa. El objetivo es proporcionar ejemplos y recursos que puedan inspirar a otros a explorar nuevas ideas y técnicas en sus propios proyectos.

**La mayoria de codigo corre en el navegador por lo que no se requiere de instalaciones muy pesadas, ademas de las bibliotecas necesarias de cada proyecto.**

### Estructura del repositorio

- P5.js: Contiene ejemplos de código creativo utilizando la biblioteca P5.js para crear gráficos interactivos y visualizaciones.

- Three.js: Contiene ejemplos de código creativo utilizando la biblioteca Three.js para crear gráficos 3D y experiencias interactivas en la web.

- Processing: Contiene ejemplos de código creativo utilizando la biblioteca Processing para crear gráficos y animaciones.
